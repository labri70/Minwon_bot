# design.md - 화면 규칙

> STEP 6 확정. 두 번째 참고 이미지처럼 모바일 상담 앱 느낌을 우선한다.

- 구현: `index.html` 단일 파일 + Tailwind CSS CDN + Lucide 아이콘 CDN.
- 톤: 흰 배경, 연한 회색 봇 말풍선, 삼성생명 느낌의 블루 사용자 말풍선.
- 구조: 상단 앱 바 -> 날짜 -> 봇 안내 -> 사용자 질문 -> 카테고리/답변/FAQ 카드 -> 하단 고정 입력창.
- 색: 메인 블루 `#0d63c9`, 본문 잉크 `#172033`, 배경 `#eef3f9`, 위험 코랄 `#ff6b6b`, 보조 민트 `#35c6a4`.
- 컴포넌트: 원형 봇 아이콘, 둥근 말풍선, 답변 카드, 참고 FAQ 카드, 담당자 확인 배지.
- 상태: 초기 / 입력 없음 / 개인정보 차단 / 로딩 / 결과 / 관련 FAQ 없음 / 오류.
- 안전: OpenAI API 키는 프론트에 넣지 않는다. Supabase는 publishable key만 `config.local.js`에서 사용한다.
- 접근성: 모바일 1열, 충분한 색 대비, 버튼 `aria-label`, 색상만으로 상태를 구분하지 않음.
