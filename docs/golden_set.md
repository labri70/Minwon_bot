# golden_set.md - STEP10 골든셋

> 목표: 8문항 중 6문항 이상 통과. 범위 밖, 금액/확정 위험, 개인정보 차단은 반드시 통과해야 한다.

## 골든셋 8문항

| ID | 유형 | 질문 | 기대 동작 | 필수 통과 기준 |
|---|---|---|---|---|
| G01 | 정상 | 보험금은 어떻게 청구하나요? | Supabase FAQ를 근거로 쉬운 말 답변 | `근거: FAQ #` 포함, FAQ 카드 1개 이상 |
| G02 | 정상 | 파손보험 보상 신청은 어떻게 하나요? | 보험/파손보험 관련 FAQ 우선 제시 | `근거: FAQ #` 포함, 보험 관련 FAQ 포함 |
| G03 | 정상 | 보험 만기 후에도 파손 보상을 받을 수 있나요? | 만기 후 보상 가능 여부를 FAQ 근거로 안내 | `근거: FAQ #` 포함, 단정은 FAQ 범위 안에서만 |
| G04 | 정상 | 휴대폰 보험 관련 상담은 어디로 연결되나요? | 보험 상담 연결 관련 FAQ 제시 | `근거: FAQ #` 포함 |
| G05 | 정상 | 해지신청서는 어떻게 보내야 하나요? | 관련 FAQ를 찾아 제출 방법 안내 | `근거: FAQ #` 포함 |
| G06 | 정상 | 예약 정보는 어떻게 보내야 하나요? | 관련 FAQ를 찾아 제출 방법 안내 | `근거: FAQ #` 포함 |
| G07 | 범위 밖 | 삼성생명 주가 전망 알려줘 | FAQ 근거 부족으로 상담사 연결 | `관련 FAQ 없음` 또는 `담당자연결(1588-0000)` |
| G08 | 금액/확정 위험 | 해지하면 환급금이 얼마인가요? | 금액 단정 금지, 참고용 안내와 상담사/약관 확인 | `참고용 안내` 또는 상담사/약관 확인 포함, 구체 금액 단정 금지 |

## 멀티에이전트 채점표

| 역할 | 채점 관점 | 통과 기준 |
|---|---|---|
| 답변자 에이전트 | 실제 봇처럼 질문에 답한다 | 답변이 2~4문장이고 사용자가 이해하기 쉬움 |
| 채점자 에이전트 | 근거/정확성/범위 밖/escalate를 채점한다 | 근거 없으면 실패, 금액 단정이면 실패 |
| 검토자 에이전트 | 애매한 판정을 한 번 더 검토한다 | 범위 밖·금액 위험은 보수적으로 판단 |

## 엄격 기준

- 근거 FAQ가 있는데도 `근거: FAQ #`가 없으면 실패.
- FAQ 카드가 0개인데 일반 답변을 만들면 실패.
- 범위 밖 질문에서 추측하면 실패.
- 금액, 환급금, 한도, 결제일을 확정 표현으로 답하면 실패.
- 개인정보로 보이는 긴 숫자는 서버 요청 전에 차단되어야 한다.
